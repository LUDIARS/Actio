# Task progress visibility

UX-AT-TASK-PROGRESS-01: a task owner can see task state, dependency waits,
critical-path membership and related PR progress without matching sessions by hand.
Scenario: a Cc task has a Revisor or GitHub PR; the owner sees which repository
and PR it belongs to, review/head freshness, merge state and reflection evidence.
This draft captures the 2026-09-26 request; it does not claim visual acceptance.
