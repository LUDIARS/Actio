# ページデザインと表示モード

2026-09-29: neco の指示により Elegantia・Figmentum・Excubitor の画面に合わせ、落ち着いた配色、細い罫線、余白のあるカードと一覧を使用する。

- 見出しはページ名・機能名を簡潔に示す。詩的なタイトル、宣伝文句、装飾用の副題は不要。この方針は他の Astra デザインにも適用するというユーザー指定。
- ライト・ダーク・端末設定をログイン画面とメニューから選べる。初回は端末設定に従う。選択は localStorage の actio_theme に保存する。
- 配色は styles/theme.css、外枠・メニューは styles/layout.css、タスク一覧は pages/TasksPage.css が所有する。
- 文字用の --accent と塗り用の --accent-fill を分離し、両モードでコントラストを保つ。
- 768px 以下は開閉可能なメニューにし、閉じたメニュー内へキーボードフォーカスが移動しないようにする。
- タスクの登録・更新、認証、API の契約は変更しない。
