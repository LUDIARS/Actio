# チーム未登録タスクの一時登録 {#SPEC-AT-UNASSIGNED-INTAKE}

チームを指定せず登録するタスクについて、同期済みプロジェクトに有効なチーム所属がない場合は、既存のカテゴリ・タグ項目へ「一時登録」「要整理」を追加する。登録元が Cc workflow v3 の場合は、プロジェクト参照自体が未解決でも同じ分類を付ける。

既存分類は保持し、ラベルを重複させない。本文、所有者、作成元参照を変更しない。通常の個人タスクと未登録の外部プロジェクト参照は従来どおり扱う。チームを明示した要求の認可・所属検証は変更しない。複数所属のプロジェクトに対して所属先を自動選択しない。

登録後、タスク一覧で「要整理」を強調表示する。整理担当者が既存の編集画面で分類を修正できる。再送時は既存IDと保存済み分類を返す。

受入条件: 未所属の登録保存、分類・本文保持、再送時の冪等性、個人タスクの非変更、明示チームの検証維持。検証コード: `tests/unit/unassigned-intake.test.ts`、`tests/api/team-routes.test.ts`。実画面の受入確認結果は別途記録し、ここでは確認済みとしない。
