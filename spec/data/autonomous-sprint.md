# 自律スプリントの保存データ

Actio が所有するユーザーデータ。SQLite / PostgreSQL の `autonomous_sprint_runs` に現在のループ・方針・着手許可・警告、`autonomous_sprint_events` に変更時の状態・種別・理由・主体 ID・時刻を保存する。スプリント、タスクと本人の属性の正本は既存の各テーブルと Cernere にある。

管制操作の理由はチーム内の運用情報として扱う。クライアントシークレット、トークンやユーザーの属性は保存しない。クライアントの内部 ID は現在状態の認可だけに使い、API の返却値には含めない。履歴は運用監査用に保管し、手動へ切り戻した際も残す。
